# Trade Policy and the Green Transition Monitor

**Live dashboard:** [anaelenasc.github.io/trade-environment-monitor](https://anaelenasc.github.io/trade-environment-monitor/)

Mapping the gap between environmental commitments and trade policy behaviour. Built by [SGEPT](https://sgept.org) using [Global Trade Alert](https://globaltradealert.org) data.

---

## Repository structure

```
trade-environment-monitor/
├── index.html               ← Single-page dashboard (GitHub Pages entry point)
├── fetch_data.py            ← GTA API pipeline — writes data/indicators.json daily
├── data/
│   ├── indicators.json      ← Auto-generated by pipeline (do not edit manually)
│   └── indicators_export.csv← Flat CSV for download
├── .github/workflows/
│   └── update.yml           ← GitHub Actions: runs fetch_data.py daily at 06:00 UTC
└── README.md
```

## Indicators

### Static (updated manually)
- **FTA Environmental Commitments** — bilateral FTA pairs with environmental provisions, sourced from CLAIRK

### Dynamic (GTA API, refreshed daily)
| Indicator | Section |
|-----------|---------|
| Net policy stance on green goods (map + year slider) | Green Transition Policy Behaviour |
| Top 10 countries — green sector support measures (bar chart) | Green Transition Policy Behaviour |
| Growth of green industrial policy (trend line) | Green Transition Policy Behaviour |
| Active fossil fuel support measures (map) | Fossil Fuel Persistence |
| Fossil fuel vs green support over time (trend line) | Fossil Fuel Persistence |
| Top 10 trade remedies on green goods (bar chart) | Green Protectionism |
| Export restrictions on strategic minerals by mineral (trend + dropdown) | Green Protectionism |

## Setup

### 1. GitHub Pages
In your repo settings, set Pages source to: **Deploy from branch → `main` → `/ (root)`**

### 2. GitHub Secret
Add your GTA API key as a repository secret named **`GTA_API_KEY`**:  
`Settings → Secrets and variables → Actions → New repository secret`

### 3. First run
Trigger the workflow manually from the Actions tab to populate live data:  
`Actions → Refresh GTA Data → Run workflow`

The initial `data/indicators.json` contains mock data for visual validation before the first live run.

## Product table

All HS codes are defined in `fetch_data.py`. Categories:

| Category | Subcategories |
|----------|--------------|
| Green goods | Batteries, Fuel cells, Other green goods, Solar, Wind |
| Green fuels | Biofuel (382600), Hydrogen (280410) |
| Strategic minerals | Lithium, Copper, Cobalt, Nickel, Graphite, Rare Earths |
| Fossil fuels | Coal, Oil, Gas (revised), Petrochemicals |

**Note:** HS 281410 appears in both green goods (Other) and petrochemicals. Interventions on this code count toward both sets of indicators.

## FTA data

The FTA chord diagram and country-pairs list currently display mock data. To update with real data:

1. Prepare your FTA data as a list matching this structure:
   ```json
   [{"from": "EU", "to": "Japan", "agreement": "EU-Japan EPA", "year": 2019, "provisions": 25}]
   ```
2. Replace the `FTA_COUNTRY_PAIRS` list in `fetch_data.py`
3. Commit and push — the dashboard will update on next deploy
